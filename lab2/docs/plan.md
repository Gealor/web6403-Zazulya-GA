## Этап 5. Стилизация (CSS)

### 5.1 Шрифты
Проблема: Morpheus не содержит кириллицы.

Варианты:
1. **Morpheus + запасной кириллический шрифт.** Браузер берёт недостающие символы из следующего шрифта в списке. Morpheus использовать для латиницы и цифр (номер выпуска, цены).
   ```css
   font-family: 'Morpheus', 'Ruslan Display', serif;
   ```
2. **Найти кириллическую фанатскую версию Morpheus.** Проверить наличие всех букв, включая «ё» и «й».
3. **Близкие шрифты с кириллицей** (Google Fonts):
   - заголовки: *Ruslan Display* или *Cormorant SC*
   - текст статей: *Old Standard TT* или *PT Serif*

- [ ] Выбрать шрифты
- [ ] Скачать в `fonts/` и подключить через `@font-face` (без зависимости от интернета)

### 5.2 Основа

### 5.7 Финальные штрихи

### 5.8 Проверка селекторов
Минимум 3 вида, план использования:

| Вид селектора | Пример |
|---|---|
| Тег | `h1`, `table`, `body` |
| Класс | `.col-price`, `.wanted-poster` |
| Идентификатор | `#masthead` |
| Потомок | `.main-nav a` |
| Псевдокласс | `a:hover`, `tr:nth-child(even)` |
| Псевдоэлемент | `.article-text::first-letter` |

## Контрольные вопросы

Объяснять на примерах из своего кода.

1. Что такое HTML и его структура? — `<!DOCTYPE>`, `html`, `head`, `body` на примере любой страницы
2. Что такое HTML-теги и их атрибуты? — `img` (`src`, `alt`), `a` (`href`), `td` (`colspan`)
3. Для чего нужны каскадные таблицы стилей (CSS)?
4. Какие возможности CSS? — цвета, шрифты, раскладка, псевдоклассы
5. Как подключить CSS, синтаксис? — свой `<link>` в `head`; также `style` и инлайн
6. Что такое блочная модель CSS? — на примере карточки объявления: content, padding, border, margin
7. Какие существуют единицы измерения и цвета? — `px`, `em`, `rem`, `%`, `vw`; `#hex`, `rgb()`, `hsl()`, имена цветов
